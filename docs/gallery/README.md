# Example gallery

These pages are generated by `node scripts/build-gallery.js` from the sample files in this repository. Each one shows the output of a command-line tool, so you can see what it produces before you run it on your own scripts.

- [Main inbound line (example)](main-inbound.md): The sample script that ships with the viewer: hours check, menu, CRM lookup and queue routing.
- [A flow with problems](broken-flow.md): A deliberately broken script: an unreachable step, a loop with no exit, a menu with no timeout and a missing target.
- [CXone reference-list check](reference-check.md): Skill, hours-profile and script names checked against exported CXone lists.
- [Comparing two versions](version-diff.md): A changed greeting and a new promo step, as the diff command reports them.
