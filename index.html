The buttons on this page can't run where it's open right now. This page needs JavaScript, and the place it's open is blocking scripts. SharePoint, OneDrive, Teams, Google Drive, email previews and file preview panels all do this, so the page shows but nothing responds. To use it:
  1. Download the .html file and open it in Chrome, Edge, Safari or Firefox (double-click it, or drag it into a browser window).
  2. Or put it on a site that serves web pages, such as GitHub Pages, Azure Static Web Apps, Netlify or an IIS intranet server.
  3. Or use the claude.ai version of this page, which also reads screenshots and photos and keeps a shared library.
